## 写作纪律

- **一个机制只在一处详述。** 引用方只写"见 02 §x"，不复制内容。
- 文档与代码冲突时，以文档为准；确认要改行为，先改文档再改代码。
- 未落地的设想不写成既定事实，一律进 01 的「待决问题」或标「后续」。
