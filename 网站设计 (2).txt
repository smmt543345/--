# 历史学读书会网站：从零开发到 AI 持续更新完整指南

下面是一份完整的开发与维护指南，涵盖从需求分析、技术设计、后端开发、前端开发，到用 AI 持续更新的全流程。每个部分都配有中文说明，你可以按顺序阅读和执行。


# 第一部分：项目概述与需求分析

## 1.1 项目背景

历史学读书会需要一个专属网站，用于管理活动签到、沉淀书目库、促进成员交流、发布读书会动态。网站以 Web 形式呈现，手机浏览器可正常访问，后续可扩展为微信小程序。

## 1.2 核心功能

| 模块 | 功能 | 说明 |
|---|---|---|
| 用户系统 | 注册、登录、个人中心 | JWT 鉴权，角色分为游客、成员、管理员 |
| 活动签到 | 创建活动、签到、签到统计 | 支持时间窗校验、重复签到拦截 |
| 书目库 | 添加书目、推荐审核、搜索筛选 | 每本书可关联多次活动 |
| 交流论坛 | 发帖、评论、点赞 | 可关联书目或活动 |
| 动态发布 | 管理员发布通知、首页展示 | 支持置顶 |
| 通知系统 | 被评论通知、活动提醒 | 迭代功能 |

## 1.3 角色权限

- **游客**：浏览公开内容
- **成员**：签到、发帖、评论、推荐书目
- **管理员**：全部权限 + 活动管理、书目审核、动态发布

## 1.4 页面清单

| 页面 | 路由 | 核心功能 |
|---|---|---|
| 登录/注册 | `/login` `/register` | 身份认证 |
| 首页 | `/` | 动态、近期活动、最新书目、最新帖子 |
| 活动列表/详情 | `/events` `/events/:id` | 浏览、签到 |
| 书目库/详情 | `/books` `/books/:id` | 搜索筛选、元数据、讨论 |
| 交流区/帖子详情 | `/forum` `/forum/:id` | 发帖、评论 |
| 动态列表 | `/news` | 公告浏览 |
| 个人中心 | `/me` | 我的签到、帖子、推荐 |
| 管理后台 | `/admin` | 全模块管理 |


# 第二部分：技术架构与项目结构

## 2.1 技术栈选择

| 层级 | 选择 | 理由 |
|---|---|---|
| 后端 | Python Flask | 轻量灵活，适合快速开发 RESTful API |
| 前端 | Vue 3 + Element Plus | 组合式 API，组件库丰富，响应式适配好 |
| 数据库 | SQLite（开发）→ MySQL（生产） | 开发零配置，生产更稳定 |
| ORM | Flask-SQLAlchemy | Flask 生态最成熟的 ORM |
| 认证 | Flask-JWT-Extended | 无状态会话，便于扩展 |
| 密码加密 | Flask-Bcrypt | 安全哈希 |
| 跨域 | Flask-CORS | 前后端分离必需 |
| 迁移 | Flask-Migrate | 数据库版本管理 |
| 构建 | Vite | 前端快速构建 |
| 状态管理 | Pinia | Vue 3 官方推荐 |

# 第三部分：数据模型设计

## 3.1 核心数据表

数据模型是整个网站的地基，定义了系统中有哪些对象、对象之间如何关联。

```python
# backend/app/models.py
from datetime import datetime
from . import db

class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), unique=True, nullable=False)
    password_hash = db.Column(db.String(128), nullable=False)
    email = db.Column(db.String(120), unique=True, nullable=False)
    role = db.Column(db.String(20), default='member')  # admin/member
    created_at = db.Column(db.DateTime, default=datetime.utcnow)

    checkins = db.relationship('Checkin', backref='user', lazy=True)
    posts = db.relationship('Post', backref='user', lazy=True)

class Event(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    title = db.Column(db.String(200), nullable=False)
    description = db.Column(db.Text)
    event_date = db.Column(db.DateTime)
    location = db.Column(db.String(200))
    checkin_start = db.Column(db.DateTime)
    checkin_end = db.Column(db.DateTime)
    max_participants = db.Column(db.Integer, nullable=True)  # 人数上限
    status = db.Column(db.String(20), default='draft')
    created_by = db.Column(db.Integer, db.ForeignKey('user.id'))
    created_at = db.Column(db.DateTime, default=datetime.utcnow)

    checkins = db.relationship('Checkin', backref='event', lazy=True)

class Checkin(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    user_id = db.Column(db.Integer, db.ForeignKey('user.id'), nullable=False)
    event_id = db.Column(db.Integer, db.ForeignKey('event.id'), nullable=False)
    checkin_time = db.Column(db.DateTime, default=datetime.utcnow)
    method = db.Column(db.String(20), default='button')
    __table_args__ = (db.UniqueConstraint('user_id', 'event_id'),)

class Book(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    title = db.Column(db.String(200), nullable=False)
    author = db.Column(db.String(100))
    publisher = db.Column(db.String(100))
    year = db.Column(db.Integer)
    isbn = db.Column(db.String(20))
    cover_url = db.Column(db.String(500))
    description = db.Column(db.Text)
    tags = db.Column(db.String(200))
    status = db.Column(db.String(20), default='pending')  # pending/approved/archived
    added_by = db.Column(db.Integer, db.ForeignKey('user.id'))
    created_at = db.Column(db.DateTime, default=datetime.utcnow)

class EventBook(db.Model):
    event_id = db.Column(db.Integer, db.ForeignKey('event.id'), primary_key=True)
    book_id = db.Column(db.Integer, db.ForeignKey('book.id'), primary_key=True)

class Post(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    user_id = db.Column(db.Integer, db.ForeignKey('user.id'), nullable=False)
    book_id = db.Column(db.Integer, db.ForeignKey('book.id'), nullable=True)
    event_id = db.Column(db.Integer, db.ForeignKey('event.id'), nullable=True)
    title = db.Column(db.String(200), nullable=False)
    content = db.Column(db.Text, nullable=False)
    is_top = db.Column(db.Boolean, default=False)
    is_essence = db.Column(db.Boolean, default=False)
    status = db.Column(db.String(20), default='normal')
    created_at = db.Column(db.DateTime, default=datetime.utcnow)

    comments = db.relationship('Comment', backref='post', lazy=True)

class Comment(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    post_id = db.Column(db.Integer, db.ForeignKey('post.id'), nullable=False)
    user_id = db.Column(db.Integer, db.ForeignKey('user.id'), nullable=False)
    content = db.Column(db.Text, nullable=False)
    created_at = db.Column(db.DateTime, default=datetime.utcnow)

class News(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    title = db.Column(db.String(200), nullable=False)
    content = db.Column(db.Text, nullable=False)
    cover_url = db.Column(db.String(500))
    is_top = db.Column(db.Boolean, default=False)
    author_id = db.Column(db.Integer, db.ForeignKey('user.id'))
    published_at = db.Column(db.DateTime, default=datetime.utcnow)

class Notification(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    user_id = db.Column(db.Integer, db.ForeignKey('user.id'), nullable=False)
    type = db.Column(db.String(50))  # comment/checkin_reminder/approve
    content = db.Column(db.Text)
    is_read = db.Column(db.Boolean, default=False)
    created_at = db.Column(db.DateTime, default=datetime.utcnow)
```

## 3.2 表关系说明

- User ↔ Event：一个管理员创建多个活动（一对多）
- User ↔ Checkin ↔ Event：用户通过签到表与活动建立多对多关系
- Event ↔ Book：通过 event_books 中间表实现多对多
- Post 可选关联 Book 或 Event，也可都不关联（自由讨论）
- Post ↔ Comment：一个帖子有多个评论（一对多）
- Notification 关联用户，用于站内通知

## 4.3 权限装饰器

**app/utils/auth_middleware.py**
```python
from functools import wraps
from flask import request, jsonify
from flask_jwt_extended import verify_jwt_in_request, get_jwt_identity
from app.models import User

def require_login(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        try:
            verify_jwt_in_request()
        except Exception:
            return jsonify({'error': '未登录或 Token 无效'}), 401
        identity = get_jwt_identity()
        user = User.query.get(identity['id'])
        if not user:
            return jsonify({'error': '用户不存在'}), 401
        request.current_user = user
        return func(*args, **kwargs)
    return wrapper

def require_admin(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        try:
            verify_jwt_in_request()
        except Exception:
            return jsonify({'error': '未登录或 Token 无效'}), 401
        identity = get_jwt_identity()
        user = User.query.get(identity['id'])
        if not user or user.role != 'admin':
            return jsonify({'error': '无管理员权限'}), 403
        request.current_user = user
        return func(*args, **kwargs)
    return wrapper
```

## 4.4 认证模块

**app/routes/auth.py**
```python
from flask import Blueprint, request, jsonify
from flask_jwt_extended import create_access_token, jwt_required, get_jwt_identity
from app import db, bcrypt
from app.models import User

auth_bp = Blueprint('auth', __name__)

@auth_bp.route('/api/auth/register', methods=['POST'])
def register():
    data = request.get_json()
    username = data.get('username')
    email = data.get('email')
    password = data.get('password')

    if not username or not email or not password:
        return jsonify({'error': '缺少必填字段'}), 400
    if User.query.filter_by(username=username).first():
        return jsonify({'error': '用户名已存在'}), 409
    if User.query.filter_by(email=email).first():
        return jsonify({'error': '邮箱已注册'}), 409

    password_hash = bcrypt.generate_password_hash(password).decode('utf-8')
    user = User(username=username, email=email, password_hash=password_hash)
    db.session.add(user)
    db.session.commit()
    return jsonify({'message': '注册成功', 'user_id': user.id}), 201

@auth_bp.route('/api/auth/login', methods=['POST'])
def login():
    data = request.get_json()
    username = data.get('username')
    password = data.get('password')

    user = User.query.filter_by(username=username).first()
    if not user or not bcrypt.check_password_hash(user.password_hash, password):
        return jsonify({'error': '用户名或密码错误'}), 401

    access_token = create_access_token(identity={'id': user.id, 'role': user.role})
    return jsonify({
        'token': access_token,
        'user': {'id': user.id, 'username': user.username, 'role': user.role}
    }), 200

@auth_bp.route('/api/auth/me', methods=['GET'])
@jwt_required()
def get_me():
    identity = get_jwt_identity()
    user = User.query.get(identity['id'])
    if not user:
        return jsonify({'error': '用户不存在'}), 404
    return jsonify({
        'id': user.id,
        'username': user.username,
        'email': user.email,
        'role': user.role
    }), 200
```

**app/routes/events.py**
```python
from datetime import datetime
from flask import Blueprint, request, jsonify
from app import db
from app.models import Event, Checkin
from app.utils.auth_middleware import require_login, require_admin

event_bp = Blueprint('event', __name__)

@event_bp.route('/api/events', methods=['GET'])
def list_events():
    events = Event.query.order_by(Event.event_date.desc()).all()
    result = []
    for e in events:
        result.append({
            'id': e.id,
            'title': e.title,
            'description': e.description,
            'event_date': e.event_date.isoformat() if e.event_date else None,
            'location': e.location,
            'max_participants': e.max_participants,
            'current_count': len(e.checkins),
            'status': e.status
        })
    return jsonify(result), 200

@event_bp.route('/api/events', methods=['POST'])
@require_admin
def create_event():
    data = request.get_json()
    event = Event(
        title=data['title'],
        description=data.get('description', ''),
        event_date=datetime.fromisoformat(data['event_date']) if data.get('event_date') else None,
        location=data.get('location', ''),
        checkin_start=datetime.fromisoformat(data['checkin_start']) if data.get('checkin_start') else None,
        checkin_end=datetime.fromisoformat(data['checkin_end']) if data.get('checkin_end') else None,
        max_participants=data.get('max_participants'),
        status=data.get('status', 'draft'),
        created_by=request.current_user.id
    )
    db.session.add(event)
    db.session.commit()
    return jsonify({'message': '活动创建成功', 'id': event.id}), 201

@event_bp.route('/api/events/<int:event_id>', methods=['GET'])
def get_event(event_id):
    event = Event.query.get_or_404(event_id)
    return jsonify({
        'id': event.id,
        'title': event.title,
        'description': event.description,
        'event_date': event.event_date.isoformat() if event.event_date else None,
        'location': event.location,
        'checkin_start': event.checkin_start.isoformat() if event.checkin_start else None,
        'checkin_end': event.checkin_end.isoformat() if event.checkin_end else None,
        'max_participants': event.max_participants,
        'current_count': len(event.checkins),
        'status': event.status
    }), 200

@event_bp.route('/api/events/<int:event_id>/checkin', methods=['POST'])
@require_login
def checkin(event_id):
    event = Event.query.get_or_404(event_id)
    if event.status not in ['published', 'checkin']:
        return jsonify({'error': '活动未开放签到'}), 400

    now = datetime.utcnow()
    if event.checkin_start and now < event.checkin_start:
        return jsonify({'error': '签到未开始'}), 400
    if event.checkin_end and now > event.checkin_end:
        return jsonify({'error': '签到已结束'}), 400

    existing = Checkin.query.filter_by(user_id=request.current_user.id, event_id=event_id).first()
    if existing:
        return jsonify({'error': '你已经签到过了'}), 409

    if event.max_participants:
        current = Checkin.query.filter_by(event_id=event_id).count()
        if current >= event.max_participants:
            return jsonify({'error': '报名已满'}), 400

    checkin_record = Checkin(user_id=request.current_user.id, event_id=event_id)
    db.session.add(checkin_record)
    db.session.commit()
    return jsonify({'message': '签到成功'}), 200

@event_bp.route('/api/events/<int:event_id>/checkins', methods=['GET'])
@require_admin
def list_checkins(event_id):
    checkins = Checkin.query.filter_by(event_id=event_id).all()
    return jsonify([{
        'user_id': c.user_id,
        'username': c.user.username,
        'checkin_time': c.checkin_time.isoformat()
    } for c in checkins]), 200
```

## 4.6 书目模块

**app/routes/books.py**
```python
from flask import Blueprint, request, jsonify
from app import db
from app.models import Book
from app.utils.auth_middleware import require_login, require_admin

book_bp = Blueprint('book', __name__)

@book_bp.route('/api/books', methods=['GET'])
def list_books():
    q = request.args.get('q', '')
    tag = request.args.get('tag', '')
    query = Book.query.filter_by(status='approved')
    if q:
        query = query.filter(Book.title.contains(q) | Book.author.contains(q))
    if tag:
        query = query.filter(Book.tags.contains(tag))
    books = query.order_by(Book.created_at.desc()).all()
    return jsonify([{
        'id': b.id, 'title': b.title, 'author': b.author,
        'publisher': b.publisher, 'year': b.year,
        'cover_url': b.cover_url, 'tags': b.tags
    } for b in books]), 200

@book_bp.route('/api/books', methods=['POST'])
@require_login
def add_book():
    data = request.get_json()
    book = Book(
        title=data['title'],
        author=data.get('author', ''),
        publisher=data.get('publisher', ''),
        year=data.get('year'),
        isbn=data.get('isbn', ''),
        cover_url=data.get('cover_url', ''),
        description=data.get('description', ''),
        tags=data.get('tags', ''),
        added_by=request.current_user.id,
        status='pending' if request.current_user.role != 'admin' else 'approved'
    )
    db.session.add(book)
    db.session.commit()
    return jsonify({'message': '书目已提交', 'id': book.id}), 201

@book_bp.route('/api/books/<int:book_id>', methods=['GET'])
def get_book(book_id):
    book = Book.query.get_or_404(book_id)
    return jsonify({

        'publisher': book.publisher, 'year': book.year, 'isbn': book.isbn,
        'cover_url': book.cover_url, 'description': book.description,
```

```python
        event_id=data.get('event_id')
    )
    db.session.add(post)
    db.session.commit()
    return jsonify({'message': '发帖成功', 'id': post.id}), 201

@post_bp.route('/api/posts/<int:post_id>', methods=['GET'])
def get_post(post_id):
    post = Post.query.get_or_404(post_id)
    return jsonify({
        'id': post.id, 'title': post.title, 'content': post.content,
        'username': post.user.username, 'created_at': post.created_at.isoformat(),
        'comments': [{
            'id': c.id, 'content': c.content,
            'username': c.user.username, 'created_at': c.created_at.isoformat()
        } for c in post.comments]
    }), 200

@post_bp.route('/api/posts/<int:post_id>/comments', methods=['POST'])
@require_login
def add_comment(post_id):
    data = request.get_json()
    post = Post.query.get_or_404(post_id)
    comment = Comment(
        post_id=post_id,
        user_id=request.current_user.id,
        content=data['content']
    )
    db.session.add(comment)

    # 给发帖人创建通知（自己评论自己不通知）
    if post.user_id != request.current_user.id:
        notification = Notification(
            user_id=post.user_id,
            type='comment',
            content=f'{request.current_user.username} 评论了你的帖子《{post.title}》'
        )
        db.session.add(notification)

    db.session.commit()
    return jsonify({'message': '评论成功', 'id': comment.id}), 201
```

```javascript
import axios from 'axios'

const request = axios.create({
  baseURL: '/api',
  timeout: 10000
})

request.interceptors.request.use(config => {
  const token = localStorage.getItem('token')
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})

request.interceptors.response.use(
  response => response.data,
  error => {
    if (error.response?.status === 401) {
      localStorage.removeItem('token')
      window.location.href = '/login'
    }
    return Promise.reject(error)
  }
)

export default request
```

## 5.3 状态管理

**src/stores/user.js**
```javascript
import { defineStore } from 'pinia'
import request from '@/api/request'

export const useUserStore = defineStore('user', {
  state: () => ({
    token: localStorage.getItem('token') || '',
    userInfo: null
  }),
  actions: {
    async login(username, password) {
      const res = await request.post('/auth/login', { username, password })
      this.token = res.token
      this.userInfo = res.user
      localStorage.setItem('token', res.token)
    },
    async fetchUserInfo() {
      this.userInfo = await request.get('/auth/me')
    },
    logout() {
      this.token = ''
      this.userInfo = null
      localStorage.removeItem('token')
    }
  }
})
```

```javascript
  { path: '/forum/:id', component: () => import('@/views/PostDetail.vue') },
  { path: '/me', component: () => import('@/views/Profile.vue'), meta: { requiresAuth: true } },
  { path: '/admin', component: () => import('@/views/Admin.vue'), meta: { requiresAuth: true, requiresAdmin: true } }
]

  history: createWebHistory(),
  routes
})

router.beforeEach((to, from, next) => {
  const userStore = useUserStore()
  if (to.meta.requiresAuth && !userStore.token) {
    next('/login')

    next('/')
  } else {
    next()
  }
})
```

## 7.6 注意事项

- **不要直接让 AI 改生产数据库**，先在本地或测试环境验证。

- **AI 生成的代码必须审查**，尤其是权限、SQL、用户输入处理。
- **保留旧版本**，Git 提交历史就是你的后悔药。
- **让 AI 写测试**，测试是防止更新引入 bug 的最好手段。
- **复杂功能先让 AI 出方案**，不要直接说“给我代码”。
